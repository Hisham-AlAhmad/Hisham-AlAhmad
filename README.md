# 💫 About Me

Full-stack developer who enjoys turning messy real-world workflows into clean, reliable software. I'm passionate about problem-solving, pick up new tools quickly, and focus on user-friendly, client-focused applications built with modern technologies.

- 💼 Full-Stack Developer at **Radikal**, working on a digital wallet and marketplace platform for unbanked vendors in Haiti
- 🚀 Shipped full-stack projects end to end: SaaS booking, real-time collaboration, e-commerce and a live freelance store
- 🧩 Comfortable across stacks: React and Next.js, Node, Django, FastAPI and Flask, with PostgreSQL and MySQL
- 🔐 Care about security and correctness: RBAC, validation, authentication flows and automated tests
- 🎓 Computer Science @ LIU, then an intensive full-stack program at **The Digital Hub**
- 🤖 Exploring AI in web apps: voice booking, deep learning and computer vision
